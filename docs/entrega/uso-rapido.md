# Uso rápido del programa

Esta guía describe un kit local generado con programa y manuales; no el repositorio de fuentes ni la demo de GitHub Pages. Para orientarte, consulta la [guía del programa](../manuales/general/guia-del-programa.md) o abre la [demo web](https://juanmavillard.github.io/grimorio/).

## Recorrido de una sesión

**Preparación → asignación → reparto opcional → noche → día → nuevas noches/días → final confirmado → revelación.**

Elige personajes y nombres siguiendo los asientos reales. Completa las decisiones secretas y confirma. Durante Noche sigue los pasos; durante Día registra nominaciones y manos. El panel Situación de la mesa te orienta sobre lo siguiente.

## Qué hace cada pantalla

| Pantalla | Úsala para |
| --- | --- |
| Grimorio | Ver personajes, estados y relaciones. Pulsa un asiento para abrir su ficha. |
| Noche | Registrar objetivos, información, notas y decisiones; revisar amanecer. |
| Día | Conversación, acusación, defensa, manos, picota, ejecución y habilidades diurnas. |
| Ayuda | Buscar personajes, reglas e interacciones o Resolver una duda. |
| Historial | Revisar acciones y explicaciones; 50 registros por página. |
| Diagnóstico | Revisar avisos, versiones, espacio y puntos de recuperación. |
| Partidas | Descargar/cargar JSON, gestionar borradores y abrir recuperación. |
| Revelación | Enseñar reparto tras el final confirmado. |

## Lo que conviene recordar

- **Guardar notas** guarda texto; **Resolver cambio** usa el motor; **Corrección avanzada** altera el registro y necesita revisión.
- **Deshacer/Rehacer** depende de las copias disponibles. Deshacer no retira información que alguien ya vio.
- **Plaza pública** muestra datos públicos; **Tapar** oculta secretos. La vista del Espía contiene secretos por diseño.
- Los temporizadores son avisos de ritmo: no ejecutan ni cierran fases.
- Las decisiones opcionales del Narrador deben confirmarse; el programa no escucha conversaciones ni juzga la locura automáticamente.

## Guardar y cambiar de ordenador

Se guarda una sola partida activa automáticamente. Espera a ver **Guardado** antes de cerrar. Descarga su JSON si quieres conservarla o llevarla a otro ordenador y después usa Cargar partida allí. El archivo contiene secretos.

Nueva partida ofrece guardar copia, continuar sin guardar o cancelar. Guardar copia deja la partida activa; repite la operación para sustituirla cuando ya estés preparado.

Si falla el guardado, descarga lo disponible y abre Recuperación. Los borradores son formularios sin confirmar, no acciones resueltas. Evita abrir la misma partida en varias pestañas.

## Atajos

Fuera de campos de texto: **G** Grimorio, **N** Noche, **D** Día, **H / ?** Ayuda, **T** Plaza pública, **Escape** salir de la cubierta. Noche y Día solo se abren en su fase.
