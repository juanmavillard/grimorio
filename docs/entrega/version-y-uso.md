# Versión, alcance y condiciones de uso

Esta guía describe un kit local generado con programa y manuales; no el repositorio de fuentes ni la demo de GitHub Pages. Para orientarte, consulta la [guía del programa](../manuales/general/guia-del-programa.md) o abre la [demo web](https://juanmavillard.github.io/grimorio/).

## Qué contiene esta preparación

Grimorio privado · Base 3, versión **1.0.1**: aplicación de la plataforma indicada (Mac universal o Windows x64), manuales de uso en HTML y tres hojas públicas de personajes en PDF. Los personajes se distribuyen en cuatro páginas por guion: Aldeanos, Forasteros, Esbirros y Demonios. Las habilidades están parafraseadas.

Esta carpeta no contiene partidas, nombres de jugadores, notas, exportaciones privadas, perfiles de navegador ni credenciales. Los ejemplos de los manuales son didácticos. El programa crea su almacenamiento en el perfil de quien lo abre; no guarda partidas dentro de esta carpeta ni las incorpora al ejecutable.

No se incluyen código fuente, dependencias de desarrollo ni informes técnicos del proyecto. Los manuales permiten empezar y consultar; los enlaces oficiales requieren conexión.

## Sistemas y comprobaciones

| Sistema | Situación |
| --- | --- |
| Mac Apple Silicon, macOS 13 o posterior | Aplicación incluida y ejecución comprobada en el equipo de desarrollo. |
| Mac Intel, macOS 13 o posterior | Binario incluido en la aplicación universal; ejecución real pendiente. |
| Windows 10/11 x64 | Ejecutable portátil generado desde Mac y contenido comprobado; ejecución real en Windows pendiente. |
| iPhone, iPad y Android | Esta aplicación de escritorio no se instala en estos dispositivos. |

La aplicación no está notarizada ni dispone de certificado comercial. No se garantiza una apertura sin avisos. No se ha probado la primera apertura en otra cuenta del sistema ni en todos los ordenadores de destino.

La revisión 1.0.1 superó 196 pruebas Node, recorridos web y pruebas del paquete Mac. Esto no acredita una auditoría exhaustiva de todas las interacciones de los 72 personajes. La ayuda es un asistente guiado: consulta las fuentes y conserva tus decisiones de Narrador.

No incluye Viajeros, Fábulas, guiones personalizados, cuentas, telemetría ni multijugador remoto. JSON de partida 4 e IndexedDB 2; los datos y copias de seguridad siguen sus límites documentados.

## Antes de compartir

El apartado 4, Digital & Online, de las [condiciones oficiales de Blood on the Clocktower](https://bloodontheclocktower.com/pages/terms-of-use) permite crear herramientas electrónicas para uso personal y restringe compartirlas o distribuirlas. Preparar una carpeta local no concede permiso para enviarla, tampoco por el hecho de que sea gratuita o se destine a amigos.

Antes de entregar copias, solicita a The Pandemonium Institute una autorización para tu caso y conserva su respuesta. Puedes consultarles en storyteller@bloodontheclocktower.com. El generador de kits no envía ni publica sus resultados automáticamente; el despliegue de la demo web se gestiona por separado.

La traducción y los materiales derivados también quedan sujetos a sus condiciones. No se incorporan recursos gráficos oficiales. La aplicación es un proyecto no oficial y no está afiliada ni patrocinada por The Pandemonium Institute o Steven Medway.

## Actualizar o pedir ayuda

Guarda un JSON si quieres proteger una partida, cierra el programa y sustituye la aplicación por otra versión con la misma identidad. No hace falta mover los datos del perfil. Si cambias de ordenador, utiliza exportación e importación.

Para explicar un fallo, indica versión, sistema, guion, fase, qué hiciste y qué esperabas. Puedes exportar un diagnóstico anónimo. No envíes un JSON completo o un rescate con secretos sin revisarlo. Ante un problema de arranque, utiliza el menú Recuperar partidas y conserva los datos antes de intentar una limpieza.
