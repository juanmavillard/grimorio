# Empieza aquí · Grimorio Base 3

Esta carpeta reúne el asistente de Narrador y lo necesario para aprender a utilizarlo. El juego es presencial: una persona dirige con el ordenador y las demás juegan sentadas alrededor de una mesa o en círculo.

**No necesitas leerlo todo. Elige tu recorrido.** La aplicación no es una partida multijugador por Internet. Los jugadores no necesitan instalar nada.

## Solo voy a jugar

1. Lee [Cómo se juega: introducción para jugadores](../manuales/general/guia-jugadores-nuevos.md).
2. Abre la hoja PDF del guion que os indique el Narrador. Para empezar, utilizad **Trouble Brewing**.
3. Pregunta cualquier duda al Narrador. No necesitas consultar el almanaque ni los procedimientos privados.

## Voy a narrar por primera vez

1. Lee [Qué leer y para qué](que-leer.md) para orientarte.
2. Sigue [Tu primera partida paso a paso](primera-partida.md).
3. Aprende los controles con [Uso rápido del programa](uso-rapido.md).
4. Antes de dirigir, consulta las [reglas generales](../manuales/general/reglas-generales.md), la [guía de Trouble Brewing](../manuales/guiones/trouble-brewing/guia-del-guion.md) y las fichas de los personajes que hayas elegido.
5. Ten a mano la [referencia rápida de Trouble Brewing](../manuales/guiones/trouble-brewing/referencia-rapida.md).

No empieces por Bad Moon Rising o Sects & Violets si nadie conoce todavía el sistema. Sus muertes, cambios de personaje y decisiones añaden complejidad.

## Ya conozco el juego

Abre la aplicación y consulta [Uso rápido](uso-rapido.md). La [guía completa del programa](../manuales/general/guia-del-programa.md) explica cada pantalla; el [manual de archivos y recuperación](../manuales/general/guardado-y-recuperacion.md) explica cómo guardar y trasladar partidas.

## Abrir el programa

Se preparan carpetas separadas para **Mac** y **Windows**. Utiliza la correspondiente a tu ordenador; la cabecera de estos manuales y el nombre del ZIP indican cuál tienes.

1. Extrae todo el ZIP antes de empezar; conserva juntas sus carpetas para que funcionen los enlaces de los manuales.
2. En la carpeta Mac, abre `01-Programa/Grimorio Base 3.app`. Requiere macOS 13 o posterior y puedes moverla a Aplicaciones. Es universal Intel/Apple Silicon; la ejecución se ha comprobado en Apple Silicon, no todavía en Intel.
3. En la carpeta Windows, abre `01-Programa/Grimorio-Base3-1.0.1-Windows.exe`. Es portátil para Windows 10/11 de 64 bits: no necesita instalación, Node ni Python. Se ha comprobado su contenido al generarlo desde Mac; la ejecución real en Windows sigue pendiente.
4. Si el sistema bloquea una aplicación no firmada, consulta [Apertura y solución de problemas](../manuales/general/aplicacion-de-escritorio.md). Autoriza individualmente solo una copia cuya procedencia conozcas; no desactives las protecciones del equipo.

Los manuales HTML se abren con doble clic en tu navegador y funcionan sin Internet. Los PDF se abren en Vista Previa u otro lector. No hace falta instalar herramientas.

Una `.app` de Mac no funciona en Windows, ni el `.exe` de Windows en Mac. Ninguna de estas entregas de escritorio se instala en iPhone, iPad o Android.
