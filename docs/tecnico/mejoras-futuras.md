# Mejoras futuras

## Fuera de esta consolidación

Viajeros, Fábulas y guiones personalizados requieren una ampliación reglamentaria propia. No forman parte de la versión 1.0.1. No se añaden cuentas, telemetría ni sincronización externa.

IndexedDB ya es el almacenamiento de la aplicación, no una mejora futura. El almacenamiento incremental solo se reconsiderará si las mediciones reales lo justifican. La auditoría individual de reglas mantiene sus casos pendientes y no se declara cerrada por tener hojas o pruebas generales.

## Comprobaciones externas pendientes

Windows real, Mac Intel, Safari/iOS, VoiceOver y primera apertura con las protecciones del sistema requieren comprobación en esos entornos. Consulta la [matriz de escritorio](escritorio.md) y el [estado de cobertura](estado-de-cobertura.md).

La incorporación de contenido futuro deberá incluir fuente oficial, ayuda, documentación y pruebas. Los casos reglamentarios y plataformas pendientes se siguen en el estado de cobertura y la matriz de escritorio. Las regresiones corregidas se conservan como pruebas, no como una lista de errores actuales.
